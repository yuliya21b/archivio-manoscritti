# Archivio digitale di manoscritti
## Descrizzione
Questo progetto è un archivio digitale dedicato alla raccolta e alla descrizione di manoscritti.
## Obiettivo

L'obiettivo è organizzare informazioni su manoscritti e testi storici attraverso HTML, XML, JSON, TEI.

## Tecnologie utilizzate

- HTML

- XML

- JSON

- TEI

## Autore
Progetto realizzato per il corso di Tecnologie Web.

## Esrcizio XPath

l'espressione XPath per individuare tutti i luoghi presenti nel documento TEIè:

`//*[local-name()='placeName']`
